# 芬芬姐版视觉 DNA

视觉母版：`/Users/yang.guo04/Downloads/ALA公司品牌治理看板｜单文件版.htm`

## 视觉气质

- 定位：直接给管理层阅读的经营汇报看板，不做产品官网式的概念表达。
- 关键词：稳重、信息密度高、层级清楚、部门责任可追溯。
- 形状语言：大面积方正矩形，卡片基本不使用圆角；状态标签可保留小圆角。
- 阴影：只用于区分大区块，强度很轻；不以悬浮卡片制造层级。

## 字体与密度

- 字体：系统无衬线，优先苹方/微软雅黑。
- 页面标题约 27px；区块标题约 19–21px；卡片标题约 14–15px。
- 笔记本端正文不低于 12px，表格正文 13px，避免 7–9px 的压缩式 UI 字号。
- 英文区块标签为 11px、加粗、加字距，仅用于辅助定位。

## 布局规则

- 页头高度约 92px，导航为白底横向标签，当前页用部门色 4px 下划线。
- 内容最大宽度 1800px，桌面横向内边距 44px；中等笔记本收为 24px。
- 首页主视觉为整块深蓝：左侧整体进度，右侧周次、标题、日期、汇报部门和本周重点。
- 指标采用白底卡片，顶部 4px 颜色线；不使用渐变和大圆角。
- 表格表头使用深蓝底白字，正文用细分隔线。
- 部门页主视觉为白底，左侧 8px 部门色线，右侧独立负责人/进度区。
- 工作包、计划卡、部门拆解均沿用细边框与部门色，不引入新的产品化组件语言。

## 结构映射

首页只保留四个老板视角区块：周次与整体进度 → 四项重点指标 → 本周汇报目录 → 八部门单行目录。部门目录不在首页展开计划和协作细节，点击后进入部门页。

部门页顺序固定为：部门拆解数据 → 第 N 周工作汇报 → 部门工作计划 → 部门工作全景图。

“本周汇报”和“部门工作计划”是两套数据，不相互替代；视觉上也用表格与计划卡区分。管理层页面不显示英文区块标签，不用解释性胶囊和重复说明制造层级。
