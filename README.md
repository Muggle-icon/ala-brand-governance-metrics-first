# ALA 公司品牌治理周报看板

这是一个独立的品牌治理汇报看板原型，面向两类汇报场景：

- 首次汇报：在同一首页中按部门展开工作计划与工作全景，默认不平铺全部任务。
- 后续周报：先判断关键指标，再查看本周汇报目录，并进入对应部门查看进度、负责人、协作方和问题。

## 页面结构

首页按“高频在前、低频在后”的顺序展示：

1. 当前治理汇报周与整体完成进度
2. 部门拆解数据
3. 本周汇报目录
4. 八部门压缩工作概览
5. 按部门展开的工作计划与工作包全景

部门页按“部门指标 → 本周汇报 → 部门工作计划 → 完整任务级工作全景”展示。

笔记本阅读以 1366×768 为基础校验：核心正文不低于 12px，表头与辅助标签不低于 10px；表格在窄屏允许横向滚动，避免继续压缩文字。

> 当前内容为演示数据，只用于确认汇报逻辑与信息结构，不代表 ALA 实际经营情况。

演示版“整体完成进度”按八部门全部计划项等权平均。正式接入前，需要由 PMO 明确是否按任务、权重、预算或阶段计算。

## 使用

直接打开 `index.html` 即可运行，无需安装依赖。
